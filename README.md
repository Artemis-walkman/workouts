# Тренировки

Статический сайт на GitHub Pages с тренировками клиентов. Каждая тренировка — интерактивная страница с чек-листом подходов, таймером отдыха и полями для результатов. Прогресс сохраняется в браузере клиента (localStorage), а вписанные результаты отправляются тренеру в Google-таблицу (см. `backend/Code.gs`) и видны на `review.html`.

## Как это устроено

- `<Имя>.html` (например, `Rustam-K.html`) — личная страница клиента со всей его программой (читает `data/<Имя>.json`). Сверху — тренировки текущего блока, внизу — архив прошлых блоков. Ссылка на конкретную тренировку: `Rustam-K.html#s05`.
- `review.html` — страница тренера: результаты по клиентам и тренировкам (по паролю).
- `index.html` + `workout.html?id=...` — общий список примеров (читает `data/index.json`).
- `assets/style.css`, `assets/app.js` — общий стиль и логика.
- `backend/Code.gs` — Google Apps Script, принимающий результаты и отдающий их на `review.html`.

Никакой сборки не нужно — GitHub Pages отдаёт файлы как есть из корня ветки `main`.

## Формат программы клиента (`data/<id>.json`)

```json
{
  "id": "Rustam-K",
  "athlete": "Рустам",
  "notice": { "title": "Общее правило", "body": "Показывается во всех тренировках, если у тренировки нет своего" },
  "blocks": [
    {
      "title": "Блок 2 · 27 окт – 9 ноя",
      "sessions": [
        {
          "id": "s04",
          "title": "Тренировка 4",
          "subtitle": "Full body A",
          "date": "2026-10-27",
          "duration": 60,
          "warmup": [ { "name": "Дорожка", "sets": 1, "reps": "7 мин", "rest": 0 } ],
          "exercises": [
            { "name": "Присед", "sets": 2, "reps": 8, "rest": 90, "trackRpe": true, "trackPain": true, "cues": ["подсказка"] }
          ],
          "cooldown": [ { "name": "Растяжка", "sets": 1, "reps": "5 мин", "rest": 0 } ]
        }
      ]
    }
  ]
}
```

- Последний блок — текущий, предыдущие — архив. Новый блок дописывается в конец `blocks`.
- `id` тренировки уникален в пределах клиента и не меняется после публикации: на нём держится прогресс клиента и строки в таблице тренера.
- `date` — плановый день; тренировки выполняются по порядку, страница открывает первую невыполненную.
- Поля `meta`, `notice`, `avoid`, `progression`, `footer` можно задать на уровне клиента; поле тренировки их переопределяет.
- Файл без `blocks` (старый формат — одна тренировка на верхнем уровне) тоже работает: он показывается как одна тренировка.

## Как добавить тренировки

Напиши Claude, что загрузить (zip-пакет, файлы или просто текст с упражнениями) — он добавит новый блок в файл клиента, проверит страницу и запушит изменения.

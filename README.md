# Тренировки

Статический сайт на GitHub Pages со списком тренировок. Каждая тренировка — интерактивная страница с чек-листом подходов и таймером отдыха. Прогресс сохраняется в браузере (localStorage), без сервера и базы данных.

## Как это устроено

- `index.html` — список тренировок (читает `data/index.json`)
- `workout.html?id=...` — страница одной тренировки (читает `data/<id>.json`)
- `data/index.json` — список всех тренировок (id, title, date, duration, tags)
- `data/<id>.json` — содержимое конкретной тренировки: warmup / exercises / cooldown
- `assets/style.css`, `assets/app.js` — общий стиль и логика, одни на все тренировки

Никакой сборки не нужно — GitHub Pages отдаёт файлы как есть из корня ветки `main`.

## Формат тренировки (`data/<id>.json`)

```json
{
  "id": "leg-day-2026-09-01",
  "title": "Ноги — сентябрь",
  "date": "2026-09-01",
  "duration": 45,
  "tags": ["ноги"],
  "warmup": [ { "name": "Разминка", "sets": 1, "reps": "3 мин", "rest": 0 } ],
  "exercises": [
    { "name": "Приседания", "sets": 4, "reps": 12, "rest": 60, "notes": "необязательное примечание" }
  ],
  "cooldown": [ { "name": "Растяжка", "sets": 1, "reps": "5 мин", "rest": 0 } ]
}
```

## Как добавить новую тренировку

Просто напиши Claude содержание тренировки (упражнения, подходы/повторы, отдых) — он сам создаст `data/<id>.json`, добавит запись в `data/index.json` и запушит изменения. Ничего руками делать не нужно.
